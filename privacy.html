Privacy Policy

Last updated: November 10, 2026

Hermes Backup is a personal, single-user utility operated by the owner of the Google account being connected. This website explains how its local backup workflow uses Google Drive data.

Information accessed

The utility requests Google Drive OAuth authorization with the drive.file scope. This is intended to allow the utility to create, upload, list, update, verify, and remove application-authorized backup files and folders in the owner's Google Drive. OAuth credentials remain on the owner's device and are not published on this website.

Backup content and processing

Selected application data, Docker service recovery archives, and local configuration files are processed on the owner's computer. Backup content is encrypted locally using rclone crypt before it is uploaded to the owner's Google Drive. Backup contents and crypt passwords are not sent to this public website or to a separate Hermes Backup server.

Storage and sharing

Encrypted backup data is stored in the owner's own Google Drive account. The public website does not host backups, operate a user database, or offer public accounts. The operator does not sell or share Google user data with advertisers or third parties for advertising purposes.

Retention and deletion

Backups are managed under the owner's control. The backup workflow is designed to replace an older verified backup only after a newer encrypted backup has passed validation. The owner can delete backup files directly from their Google Drive account. Google Drive may retain deleted files in Trash according to its own settings and policies.

Revoking access

The owner can revoke the app's Google account access at Google Account connections. The owner can also remove local rclone authorization settings and delete encrypted archives from Google Drive independently.

Website analytics and cookies

This website contains no application analytics, advertising trackers, or authentication forms. It is hosted using GitHub Pages, so GitHub may process standard hosting request information under GitHub's own privacy policy.

Contact

Questions or privacy requests about the project can be submitted via the project GitHub issue tracker. Do not include secrets or private backup data in public issues.
