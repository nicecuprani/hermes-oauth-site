Hermes Backup

Personal, local-first encrypted backup utility for Google Drive.

What it does

Hermes Backup is a private, single-user backup workflow operated on the owner's own computer. It creates local recovery archives of selected applications and configuration data, encrypts backup files using rclone crypt, and transfers encrypted copies to a folder in the owner's Google Drive account.

Google Drive access

It uses the Google Drive API with the drive.file OAuth scope to manage files created or authorized for the application. It is not intended to browse or index unrelated personal Drive files.

Who can use it

This is a personal utility, not a hosted backup service or a commercial product. There is no public account registration, online control panel, or third-party access to backup content.

Privacy

Read the Privacy Policy for details on data access, local processing, storage and revoking access.

Contact

Questions about this personal utility can be raised via the GitHub repository issue tracker. Do not post credentials or private backup data in a public issue.
